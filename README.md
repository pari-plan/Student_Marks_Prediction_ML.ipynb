# Student_Marks_Prediction_ML.ipynb
# Student Marks Prediction Using Machine Learning

## 📌 About the Project
The Student Marks Prediction System is a beginner-friendly Artificial Intelligence project that uses Machine Learning to predict student marks based on the number of hours they study.

The project uses the **Linear Regression** algorithm to learn the relationship between study hours and marks and estimate marks for a new input.

## 🎯 Objectives
- Understand the fundamentals of Machine Learning.
- Create and analyze a dataset.
- Train a Linear Regression model.
- Predict marks based on study hours.
- Evaluate the model using regression metrics.
- Visualize the relationship between study hours and marks.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Environment:** Google Colab
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn
- **Algorithm:** Linear Regression

## 📂 Project Workflow
1. Import the required Python libraries.
2. Create a sample dataset containing study hours and marks.
3. Visualize the dataset using a scatter plot.
4. Split the data into training and testing sets.
5. Train the Linear Regression model.
6. Evaluate predictions using MAE, RMSE, and R² score.
7. Enter study hours and generate a predicted score.
8. Compare actual and predicted marks visually.

## 📊 Dataset
This project uses a small **synthetic dataset of 20 sample records**. It contains two columns:

- `Study_Hours`: Number of hours spent studying.
- `Marks`: Sample marks out of 100.

The dataset is created for educational demonstration and does not represent real student records.

## 🤖 Machine Learning Algorithm
Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values.

It models the relationship between the input and output using the equation:

**y = mx + c**

Where:
- `y` represents predicted marks.
- `x` represents study hours.
- `m` represents the slope.
- `c` represents the intercept.


## ▶️ How to Run the Project

4. View the dataset, graph, and model evaluation results.
5. Enter study hours when prompted to generate a prediction.

## ⚠️ Limitations
This project uses a small synthetic dataset and only one input feature. Actual academic performance depends on many factors, so the predictions should not be used to estimate real students' marks reliably.
